# Everlook notes

These pages are for people working on this addon. The game does not load this folder. Leave every file here out of the TOCs.

Everlook is a quality-of-life addon. It does not collect world data, sign anything, or keep a journey. Each optional module is its own addon in `Everlook_<Name>` and depends on the core in `Everlook`. [Quality of life](qol.md) says how a module registers. A minimap button opens settings.
