# Retail source URLs

Prefer the official org. Classic forks and 3.3.5 ports are listed only so they can be skipped.

## Client and docs

| Source | URL |
| --- | --- |
| FrameXML | https://github.com/Gethe/wow-ui-source |
| Settings API | https://warcraft.wiki.gg/wiki/Settings_API |
| Settings menu guide | https://warcraft.wiki.gg/wiki/Creating_a_settings_menu |
| Minimap / cluster | search `MinimapCluster` in wow-ui-source `Interface/` |
