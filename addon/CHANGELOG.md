# Changelog

## 1.0.0

Everlook is a quality-of-life addon. The world-data collection, signing, journey, and the catalog modules (Map pins, Tooltip links, and the Data pack) are gone. Saved variables those features wrote are cleared on load. Item and creature tooltips keep ids, vendor price, and bag totals. Sell junk decides from the game's own item info. Quest levels use the game's quest level. Flight time no longer reports a route back to a collector.
